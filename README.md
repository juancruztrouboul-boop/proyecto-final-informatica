# Conectados - Proyecto integrador de informática

Sitio web educativo que reúne contenidos trabajados durante el año: Internet, protocolos, navegadores, desarrollo web con HTML/CSS/JavaScript, páginas estáticas y dinámicas, seguridad informática, malware y comunicación satelital.

## Cómo verlo
Abrir `index.html` en un navegador. No requiere instalación ni dependencias.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable a celulares y computadoras.
- `script.js`: menú móvil y acordeón interactivo.
