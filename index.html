01 / INTERNET

Una red que conecta al mundo

01

Historia de Internet

Internet nació como un proyecto de comunicación entre computadoras y fue creciendo hasta convertirse en una red mundial que permite compartir información.

02

Protocolos

Los protocolos son reglas que permiten que los dispositivos se comuniquen. Algunos ejemplos son TCP/IP, HTTP, HTTPS, FTP y DNS.

03

Navegadores

Los navegadores permiten acceder a sitios web. Entre los más conocidos están Google Chrome, Mozilla Firefox, Microsoft Edge y Safari.

02 / DESARROLLO WEB

¿Cómo se construye una página?

HTML organiza el contenido, CSS define su apariencia y JavaScript agrega interacción.

HTML

Estructura

Define títulos, párrafos, imágenes, enlaces, listas y secciones.

<h1>Hola mundo</h1>
CSS

Diseño

Controla colores, fuentes, tamaños, espacios y adaptación a pantallas.

h1 { color: blue; }
JavaScript

Interactividad

Permite responder a acciones del usuario y modificar el contenido.

button.addEventListener(...)

03 / SEGURIDAD INFORMÁTICA

Proteger nuestros datos también importa

El malware es un software malicioso creado para dañar dispositivos, robar información o alterar su funcionamiento.

  • Virus: puede infectar archivos y propagarse.
  • Gusano: se replica y se distribuye por redes.
  • Troyano: se presenta como un programa legítimo.
  • Ransomware: bloquea o cifra archivos para exigir un pago.
  • Spyware: recopila información sin permiso.
✓

Hábitos seguros

Usar contraseñas fuertes, activar la verificación en dos pasos, actualizar los programas y evitar enlaces sospechosos.

04 / COMUNICACIÓN

Conectividad más allá de los cables

◉

Comunicación satelital

Utiliza satélites artificiales para transmitir señales entre lugares distantes. Es útil en zonas rurales, navegación, televisión, telefonía y servicios de emergencia.
